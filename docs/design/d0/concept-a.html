장점
  • 카드 23장 중 14장이 외국어 원제목인 피드를 세리프 원제목 + 한국어 키커로 조판해 가장 차분하게 읽힌다
  • 괘선 위계(이중선·2px·헤어라인)와 단 간격만으로 위계를 만들어 이미지 없이도 완성도가 나고, 대회색이 소음이 되지 않는다
  • 모든 글자를 웹폰트 2종으로 조판해 OS(애플 산돌고딕·맑은 고딕 등)와 무관하게 같은 인상을 준다
단점
  • 375에서는 단 조판이 사라져 결국 1단 목록이 된다(박스 기사 끼워 넣기로 일부 보완)
  • 정적인 무드라 경기 결과의 에너지·"오늘 새로움"이 약하다
  • 한글 명조 2굵기로 폰트가 세 시안 중 가장 무겁고, 작은 UI 글자는 고딕보다 덜 또렷하다

중. 괘선·단 그리드·리더 점·봉인 띠는 CSS만으로 되지만, 중요도별 지면 배치(머리기사·2단)와 반응형 괘선, 가림 상태 접근성 처리에 손이 간다. 상호작용 JS 8.3KB(gzip 3.0KB, 인라인: 필터·가리기·테마·공유·출처 펼침).
