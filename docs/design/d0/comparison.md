## 0. 측정 조건

- 스크린샷은 D0-04에서 찍은 것이다(DPR 1, reduced-motion, localStorage 비움). 1280 fold에는 시안 설명용 메타 띠가 펼쳐져 있다. 이 띠는 실제 제품에 없으므로, 첫 화면 판단은 띠를 뺀 수치(헤더 위끝 기준)로 했다.
- 이번에 Playwright로 다시 잰 것: 첫 화면에 5줄이 몇 줄 보이는지(375는 하단 탭 높이를 뺀다), 카드 높이, 피드 길이, axe-core WCAG 2.1 AA 검사(375·1280 × 라이트·다크 12조합), 인라인 JS gzip 크기, `docs/design/fonts/` 파일 크기, WCAG 2.x 공식으로 다시 계산한 대비비.
- 원제목은 23장 모두 고치지 않은 상태 그대로이고, 외부 참조는 0건, 375 가로 넘침도 0이다. 세 시안 모두 같은 조건이다.
