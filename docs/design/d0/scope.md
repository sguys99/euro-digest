## 9. 시안 공통 규칙 (design-concepts 에이전트 체크리스트)

- [ ] 파일 `docs/design/d0/concept-{a,b,c}.html` — 단일 정적 HTML, **외부 의존 0**(CSS·JS 인라인, `<script src>`·외부 `<link>`·`url(http…)`·`@import` 0건, 외부 URL은 기사 원문 `<a href>`만)

- [ ] 375 · 1280 × 라이트 · 다크(`prefers-color-scheme` + `data-theme` 토글), 스크린샷 4장 `screenshots/concept-x-{375,1280}-{light,dark}.png`, 375 가로 넘침 0
- [ ] 상단 **메타 띠** + HTML 첫 주석: 콘셉트 이름 · 한 줄 설명 · 장점 · 단점 · 구현 난이도(상/중/하 + 이유) · 번들/폰트 영향(패밀리·굵기·woff2 용량)
