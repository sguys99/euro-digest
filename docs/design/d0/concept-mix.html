C 대비 바뀐 점

  1. 1280 머리기사(A) imp가 가장 높은 카드 1장(06 Solanke…)을 가운데 단 전폭으로, 제목은 한 단계 크게(라틴 23 → 42px · 한글 18 → 30px), 인덱스 탭은 카드 높이만큼 늘렸다. 나머지 카드와 375는 C 그대로
  2. 1280 M1 상태(A) 우측 열이 비면 그리드를 232px + 1fr로 바꿔 중앙을 넓히고 5줄은 중앙 최상단(D2). C의 "5줄 우측 sticky" 안은 버렸다. 내비 견본에 최종 vs M1 축소 견본 + 홈을 M1 상태로 바꾸는 토글(?stage=m1)
  3. 같은 사건 연결 줄(A) 해외·국내 짝 4쌍에 "같은 소식 국내 보도 ···· 14 인터풋볼 ↓". 게재 번호로 교차 참조해 번호에 쓰임새를 줬다. 코드가 태그·클러스터 일치로 만들 수 있을 때만 표시(M1 클러스터링 연동)
  4. 대회 필터 색 면(B) 목차(1024 이상)에서 대회를 고르면 피드 머리가 그 대회 색 면 + 약칭 + 해제 버튼으로 바뀐다(200ms). 면 위 글자 대비 라이트 5.32 · 다크 5.78 이상
  5. 게재 번호 낮춤 피드 06~28을 26/32px 굵은 숫자 → 14/15px 보조색으로. "게재 번호" 안내는 부제 오른쪽 12px로 물렸다. 5줄 1~5만 크게
  6. 색 조정 크림 지면 #F3EEE3 → #F3F0EA(채도 낮춤) · 보조 지면 #E9E2D2 → #E8E4DB · 스팟 레드 #C8352B → #B32F25(면 위 글자 4.54 → 5.51) · 중요도 빈 칸 테두리 2.50/3.44 → 3.89/4.08 · 다크 티켓 보조 글자 4.95 → 5.43. 텍스트 대비 최저값 C 4.54/4.95 → 5.32/5.43
  7. opacity 글자 제거 검색 단축키·비활성 칩·버튼의 opacity를 토큰 색(--ticket-fg-2·--ink-disabled)으로 바꿨다
  8. S4 경기 없는 날 블록 유지, 높이만 줄임 — "오늘은 5줄을 쉽니다" + 이유 1줄 + '주요 뉴스로'. 날짜를 단정하지 않는다
  9. OG 견본 워드마크·날짜·호수만(5줄 첫 줄 제거 — 결과 노출 0)

장점

  • 375는 C의 강점(첫 화면 5줄, 짧고 고른 카드, 데이터 변동에 강한 번호 거터)을 그대로 지킨다
  • 1024 이상은 머리기사 1장과 필터 색 면만으로 균일한 목록(포털) 인상을 깨고 지면 위계를 만든다. 새 모티프 없이 기존 인덱스 탭·리더 점선을 다시 썼다
  • 연결 줄이 게재 번호에 쓰임새(교차 참조)를 줘 번호를 순위로 오해할 여지가 줄었다

단점

  • 머리기사는 imp 데이터에 달려 있다. imp 5가 여럿인 날은 임시 점수 순서로 정해지므로 M1-16 점수화가 확정돼야 안정된다
  • 연결 줄은 해외·국내 언어군을 넘는 같은 사건 판정이 필요하다. 지금 클러스터링은 언어군 안에서만 묶어(M1-15) 짝 정보를 어디서 만들지 정해야 한다(아래 남은 판단)
  • 1023 이하(1단)에는 대회 필터 진입점이 없다(C 원안과 같다). 색 면은 1024 이상 목차와 주소 쿼리(?comp=)에서만 보인다

중. C 1단 리스트 + 머리기사 1종(1024 이상) + 브레이크포인트 2개(lg 1024 2단 · xl 1280 3단, 같은 DOM 순서에서 열만 바꿈) + 필터 머리 색 면(인라인 JS 몇 줄) + 연결 줄(카드에 짝 id가 있어야 함). 장식은 여전히 CSS 도형(radial-gradient·writing-mode)뿐이고 이미지 0
