혼합안 — C Programme 기반 + A 1280 위계 + A 연결 줄 + B 필터 색 면

C의 매치데이 프로그램(티켓 마스트헤드·등번호·인덱스 탭·2도 인쇄)을 그대로 두고, 1280 지면 위계·M1 중앙 확장·같은 사건 연결 줄은 A에서, 대회 필터 색 면은 B에서 가져왔다.

폰트 417.8KB(C와 같은 파일) · 인라인 JS gzip 4.0KB · 텍스트 대비 최저 5.32 / 5.43 혼합안 열기 →
  1. 1280 머리기사 — imp가 가장 높은 카드 1장을 가운데 단 전폭, 라틴 제목 23 → 42px, 인덱스 탭을 카드 높이만큼. 375는 C 그대로
  2. 1280 M1 상태 — 우측 열이 비면 232px + 1fr로 중앙을 넓히고 5줄은 중앙 최상단(D2). 혼합안 홈의 "M1 공개 상태로 보기" 토글로 실제 크기 확인
  3. 같은 사건 연결 줄 — "같은 소식 국내 보도 ···· 14 인터풋볼 ↓". 게재 번호로 교차 참조, 코드가 클러스터 일치로 만들 수 있을 때만
  4. 대회 필터 색 면 — 목차에서 대회를 고르면 피드 머리가 그 대회 색 면 + 약칭 + 해제 버튼(라이트 5.32 · 다크 5.78 이상)
  5. 조정 — 게재 번호 14/15px 보조색 · 크림 채도↓ · 스팟 레드 면 위 글자 5.51 · 중요도 빈 칸 3.89 / 4.08 · opacity 글자 0 · S4 블록 유지 · OG는 워드마크·날짜·호수만

추천안

결정은 사용자 몫이다(D0-06) · 고르기 전에는 구현하지 않는다

추천

C Programme을 기반으로 A Broadsheet의 1280 지면 위계를 섞는다

  1. 매일 아침 모바일로 23~45장을 훑는 제품이다. C는 375 첫 화면(5줄 중 4줄 노출), 카드 스캔(평균 181px, 요소 위치 고정), 데이터 변동(높이 편차 최소)에서 가장 강하고, 5줄이 적은 날도 번호 거터로 버틴다.
  2. 등번호·팀시트·리그표 은유가 D1(순위표·포메이션), D2(선수·이적), D3(티켓 OG·아이콘)로 새 언어 없이 이어진다.
  3. C의 약점(1280이 균일한 목록이라 포털에 가까워지고, M1 1280에서 5줄 위치가 애매함)은 A의 지면 위계로 메운다. B는 첫인상이 가장 강하지만 피드 피로와 375 첫 화면, 습관형 운영에서 치르는 비용이 크다.
  4. 차점은 A(40점)다. U-10의 신문형 선호를 앞세운다면 A 단일안도 합리적이다.

혼합을 고르면 혼합안 concept-mix.html을 한 번 만들어 다시 확인한다(D0-07).
