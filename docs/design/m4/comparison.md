## 2. 추천 — A 낱칸

- 사용자가 D2에서 고른 "경기 하나의 결과는 가리고 집계값은 가리지 않는다"(D64 ④)를 D1 화면에 그대로 적용한다. 예외 규칙이 생기지 않고, 구현도 선수 기록의 `result-value` 묶음 방식 하나로 통일된다.
- 가림을 켜 둔 채로도 대회 화면이 순위표로 기능한다. 하루에 한 번 순위를 확인하려고 오는 독자에게 B의 봉투는 매번 한 번 더 누르게 하는 비용이다. 남는 위험(순위 변화로 짐작)은 안내 띠가 알려 준다.
- 구독은 쓰는 빈도가 낮은 '설정' 성격이라 뒤표지 한 곳이면 충분하다. 화면마다 버튼을 늘리지 않아 첫 화면 밀도가 그대로다. .ics는 D2 결정대로 맥락(입장권 · 팀 티켓 · /my)에 남긴다.

혼합 후보(사용자가 원할 때): A 기반 + **B의 라운드 '모두 보기' 띠만** 추가(행마다 결과 가림 칸은 그대로 두고, 라운드 머리에 한 번에 열기를 더함). 또는 A 기반 + **B의 한국 선수 목록 머리 RSS · .ics 짝만**.

## 3. 사용자에게 물을 것

- 결과 가리기 미확정 부분과 RSS 위치는 어느 안으로 할까요? [A 낱칸 (추천)] / [B 봉함] / [A + B의 라운드 '모두 보기' 띠] / [직접 지정]
- (B를 고르면) 순위표를 집계값 예외로 가리면, 선수 티켓의 '팀 순위·승점'도 함께 가려야 합니다. 그렇게 할까요?

## 5. 검사

- 375 · 1280 × 라이트 · 다크 × 가림 켬 · 끔 16조합: 가로 넘침 0, 콘솔 오류 0, 외부 요청 0. axe(wcag2a · 2aa · 21aa) 위반 0, 44px 미달 0
- 펼친 상태 4장(A 375 라이트 · 1280 다크, B 375 라이트 · 1280 다크): axe 0, 넘침 0. 펼치면 포커스가 드러난 값으로 옮겨 간다
- `prefers-reduced-motion: reduce`: 펼칠 때 `.is-in` 클래스를 붙이지 않고, CSS 지속 시간 0s
- 외부 참조: `<script src>` · 외부 `<link>` · `url(http` · `@import` 0건. 외부 URL은 GitHub 링크 하나뿐이다. 폰트는 `../fonts/` 상대 경로(EuroDigest Sans 400 · 800 + Barlow Condensed 600 · 800)
- 가린 값은 `display:none`이라 보조기술에서도 숨는다(블러 · 투명도 없음). 빗금 자리는 `aria-hidden`이고, 화면 밖 텍스트로 "변동 가림" · "결과 가림"을 읽어 준다
