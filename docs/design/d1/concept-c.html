시안 정보C 경기 원장일정·라운드가 주축인 원장(ledger) — 라운드별 결과·일정 타임라인을 먼저, 순위표는 전체 열을 유지하고 팀 열을 고정한 채 가로로 민다. 변동 리본이 움직인 팀을 표 행으로 잇는다.

장점

  • 정보가 가장 많다 — 375에서도 승·무·패·득실점·폼 전체 열을 잃지 않고, 라운드 결과·일정이 첫 화면
  • 1280 원장 | 표 펼침면 한 장에 이번 라운드와 순위가 함께 — "밤사이 무슨 일이 있었나" 맥락이 바로 이어진다
  • 변동 리본 → 행 도착(:target)으로 DR-08 "순위 변동 하이라이트"를 CSS만으로 충족(섬 JS 최소)

단점

  • 밀도가 높아 "Editorial, not portal" 경계에 가깝다 — 글자 13~14.5px·행 40px대, 3초 스캔은 A·B보다 약하다
  • 375 가로 스크롤 표는 승점 오른쪽 열이 처음에 잘려 보인다(밀어야 득실·폼) — 스크롤 단서·키보드 스크롤 영역 관리 필요
  • 원장이 먼저라 순위표를 찾는 사용자에게는 한 번 더 내려야 한다(375 순위표 시작 약 1,390px — 첫 화면은 6라운드 원장)

구현 난이도

중하 — 대부분 서버 렌더 표·목록과 CSS(sticky 열 · :target 도착 · 앵커 내비). 섬 JS는 미니 위젯 대회 탭뿐. sticky 열의 배경·포커스 링·:target 배경을 함께 맞추는 CSS 관리가 핵심
