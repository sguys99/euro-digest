3. 폼 "자료 없음" 점선 상자가 표를 시끄럽게 함 → 가운데 짧은 선.
4. A 1280 변동 표식이 두 자리 순위 숫자와 겹침 → 숫자 옆 flex 배치.
5. A 팀 티켓 "2 / 위" 줄바꿈, "1 차전" 띄어쓰기, 세로 피치 비율(센터 서클 타원) → 단위 붙임·비율 68/105.
6. A 견본 표가 반폭에서 전체 열을 펴 팀명이 세로로 쪼개짐 → 견본은 축약 열.

8. B 375 카드 2줄째가 넘쳐 변동이 셋째 줄로 → 변동을 1줄째 팀명 옆으로.

12. C axe `landmark-unique`(리본 nav 2개) · `color-contrast`(비활성처럼 보이던 13라운드 줄) → 견본 리본은 div, 글자 `--ink-2`.

## 8. 추천 — **A 기반 + B 팀시트 혼합**
- 순위표는 A: 375에서 가로 스크롤 없이 5행이 바로 읽히고, 1024+는 펼침 없이 전체 열이라 FR-42 열을 모두 지킨다. 새 모티프 없이 D0의 번호 거터·티켓 스텁만 넓혀 홈·뉴스와 한 권으로 이어진다.
- 팀 화면의 포메이션 구역만 B의 팀시트(피치 + 선발·교체 명단, 명단 ↔ 칸 하이라이트)로 바꾼다: A의 사이드 피치는 작고, 교체 명단의 한국 선수(김민재)처럼 이 서비스 독자에게 중요한 사실이 B에서만 보인다. 헤더는 A 티켓을 유지한다.
- C는 밀도·원장 맥락이 강점이지만 3초 스캔·Editorial 기준에서 가장 불리하다. 원한다면 C의 변동 리본만 1024+ 대회 화면에 더하는 선택지가 있다(아래 Q1 ⑤).
