시안 정보A 프로그램 리그표매치데이 프로그램의 정돈된 한 장 표 — 왼쪽 거터의 큰 순위 숫자, 구간은 거터 띠 + 글자, 모바일은 5열로 줄이고 행을 펼쳐 상세를 본다. 팀 화면은 키트 2색 스텁을 단 티켓.

장점

  • D0 문법(번호 거터·티켓 스텁·도장)을 그대로 넓혀 새 모티프가 0 — 홈·뉴스와 한 권의 프로그램처럼 이어진다
  • 375 첫 화면에 순위 1~5위가 숫자 위계(순위 > 승점)로 바로 읽히고, 가로 스크롤이 없다
  • 팀 화면 티켓 스텁 = 팀 배지(DR-05)를 키운 것 — 배지 규격 하나로 목록·헤더·위젯이 같은 표식

단점

  • 375에서 승·무·패·득실점·폼은 행을 눌러야 보인다(한 번에 비교하려면 1024 이상)
  • 펼침 행 섬 JS가 필요하다(행마다 상태). 표 안의 펼침 행은 스크린리더 읽기 순서 확인이 필요
  • 거터 큰 숫자가 5줄 등번호와 같은 문법이라, 순위가 아닌 숫자(게재 번호)와 혼동하지 않게 크기 규칙을 문서화해야 한다

구현 난이도

중 — 서버 렌더 표 + 펼침 섬(행 버튼 aria-expanded · 뜯김 모션) + 페이지 탭 섬. 1024 이상은 펼침 없이 전체 열(같은 DOM, 열만 보임 전환). 피치는 CSS 배치(SVG 선 + 절대 위치 칸)

번들·폰트 영향

폰트 변화 0 — EuroDigest Sans 400·800 + Barlow Condensed 600·800 = 417.8KB 그대로(2패밀리). 새 섬 JS 추정 gzip 약 1.1KB(행 펼침 약 0.5 · 탭 약 0.6, 미니 탭 공용) → 초기 JS 약 145KB / 160KB. 시안 인라인 JS 실측 3,254B(gzip 1,453B, 테마·토스트 포함)
