장점

  • 팀 화면 첫인상이 가장 강하다 — 키트 색 등번호 칸이 피치에 서고, 교체 명단의 한국 선수(김민재)까지 한 장에 보인다
  • 순위 카드 2줄째에 폼·득실·변동이 늘 보여 375에서도 누르지 않고 비교할 수 있다(가로 스크롤 없음)
  • 카드 = 팀 화면 링크 하나라 상호작용이 단순하다(펼침·스크롤 상태 없음)

단점

  • 순위 카드가 행당 약 72px — 20팀이 375에서 약 1,410px로 가장 길고, 승·무·패·득실점 개별 숫자는 팀 화면에서만 보인다
  • 피치가 라인업 데이터에 크게 기댄다 — 집계 경기가 적거나 포메이션이 갈리는 팀(우니온 베를린 1:1)은 히어로가 약해진다(최빈값 동률 규칙 필요)
  • 1280 두 단 사다리는 11위가 오른쪽 위로 올라가 위아래 순서를 한 번 끊는다
