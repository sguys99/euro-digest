### 계산 규칙 (시안 생성기에서 계산 — 문구는 만들지 않음)
- **출전** = 원장 `status` start · sub(출전 시간 > 0). bench(분 0) = "벤치 · 미출전", absent = "명단 제외", unknown = "라인업 없음"(출전 여부 모름 — 0으로 세지 않는다). 분 `null`은 "–"로 쓰고 0으로 바꾸지 않는다.
- **시즌 누적** = 원장 `since`(10.19) 이후 대회별 합: 출전 · 분 · 골 · 도움. 리그와 UCL을 따로 세고 컵은 `OTHER`(§6 #1). 머리에 "10월 19일 이후 집계"를 늘 쓴다(D27 ④ · FR-61). 예: 김민재 UCL 1경기 45분 · 분데스 0경기(명단 1) · 기타 0경기(명단 1) / 이재성 분데스 1경기 75분 1골 · 기타 1경기 63분.
- **최근 5경기 로그** = 원장 행 최신순 5칸. 김민재: ① 10.29 04:45 DFB 포칼 마그데부르크(홈 6-1) 벤치 ② 10.26 01:30 분데스 프라이부르크(원정 3-1) 명단 제외 ③ 10.22 04:00 UCL 아스널(홈 2-2) 선발 45분 ④⑤ "집계 시작(10.19) 전" 칸. 스코어는 소속팀 기준(`PlayerMatchLog.result` — for/against). 다른 스코어 줄은 홈-원정(DESIGN §3.5)이라 표기가 섞인다(§6 #6).
- **UCL 출전 여부**(FR-61) = UCL 리그 페이즈 행 유무와 출전 여부: 김민재 "출전 1"(45분) · 이강인 "명단 1 · 출전 0"(10.21 벤치).
- **홈 하이라이트 칩** = 그날 호의 브리핑 창(UTC 전날 하루 — 경기일 '현지') 한국 선수 행. 제 20호(10.31): 이재성 벤치 하나뿐 → **출전 0명 상태**. 붐비는 날 견본은 제 14호(10.25 — 10.24 경기): 이재성 75분 1골 · 황희찬 90분 · 정우영 76분 · 이강인 67분 · 설영우 벤치.
- **주간 리포트**(FR-90·91) = 지난 월~일 원장 합산. W43(10.19~10.25 — 집계 첫 주가 마침 월요일 시작) 7명: 이재성 1경기 75분 1골 · 황희찬 1·90 · 정우영 1·76 · 이강인 1·67(명단 2) · 김민재 1·45 · 설영우 0(벤치) · 카스트로프 0(명단 제외). 김지수(id 없음)·홍현석(비활성)은 표 밖 + 각주.
- **이번 주 MVP**(FR-92) = 골×3 + 도움×2 + 출전 경기 수(코드). W43: 이재성 4점(3 + 0 + 1) — 나머지는 1점 이하 → MVP 이재성. 동점 규칙이 PRD에 없다(§6 #3).
- **이적 진행 바**(FR-100~102, DESIGN §2.7) = 단계명 그대로 `rumor`(루머) → `negotiating`(협상) → `agreed`(합의) → `official`(공식), 예외 `collapsed`(결렬 — 빈 구멍 4 + 사선). 역행 없음. 펀치 구멍 채운 수 = 단계(1~4). 김민재 = 루머 1/4 · Tier 3 · 최근 갱신 10.29 16:15 KST(10.30 호 카드 `src.at`) · 타임라인 2건(10.17 18:35 · 10.29 16:15, 인터풋볼). 알바레스 = 결렬 · Tier 3 · 10.10 · 행선지 없음. 로호 = 공식 4/4 · Tier 3 · 10.10 · 행선지 없음(`to` 필드 없음).
- **잠잠**(FR-106) = 마지막 갱신 + 30일 < 기준 시각. 10.31 기준 가장 오래된 갱신이 10.10(21일)이라 실데이터에는 없다 → 견본.
- **Tier** = 카드 최고 출처 Tier(`Source.tier`). 기사 속 원 보도자는 반영하지 않는다(D23).
- **검색** = Pagefind 결과를 유형(선수 · 팀 · 뉴스) 묶음으로. 한/영 별칭은 인덱스 메타(FR-131). 결과 수는 위 실데이터로 센다.
- **시각** UTC 저장값 → KST 표시(+9h, `src/lib/time.ts`). 10.25 유럽 서머타임 종료 전후 경기 모두 같은 규칙.

## 5. 가정
- 호수 · 발행 시각은 D0 규칙 그대로(창간 2026-10-12 → 10.31 = 제 20호, 겨울 발행 07:30).
- 선수 이름: 등록 한국 선수는 `nameKo`(한글) + `nameEn`(영문, 상세 머리 보조). 원장의 API 원문 표기("Kim Min-Jae")는 쓰지 않고 `apiFootballId`로만 맞춘다(FR-60). 상대 팀명은 `names.ko.json` 정확 일치일 때만 한글, 없으면 영문 원문(D63 ①과 같은 규칙).
- 이적 카드의 선수 · 팀 이름은 `transfer.player/to` slug를 `names.ko.json`으로 바꾼다. `from`이 없으면 비운다 — 소속 설정으로 채우지 않는다(D23). '현 소속' 표기는 §7 Q3.
- 마이 팀 표본(`/my` · 온보딩 선택 상태)은 실데이터가 아니라 시안 표본이다(§7 Q2 추천: 팀 바이에른 뮌헨 · 아틀레티코 마드리드 · 아스널 + 선수 김민재 · 이강인).
- 검색 결과는 실제 카드 제목 · 팀 · 선수만으로 만든다. Pagefind 기본 UI는 쓰지 않고 JS API를 첫 입력 때 지연 로드하는 것으로 가정한다 — 초기 JS 영향 0(DR-11, 실측은 M4-16).
- 팔로우 한도는 온보딩의 팀 최대 5(FR-113)만 PRD에 있다. `/my`의 전체 한도는 시안에서 5로 보이고 M4-07에서 정한다.

## 6. 범위 정리 중 발견한 데이터 · 규칙 이슈 (M3 · M4 참고)
1. **컵 대회 이름이 사라진다** — 원장의 DFB 포칼 행은 `comp: null` + `league: "DFB Pokal"`인데, `PlayerMatchLog.comp`·`PlayerSeasonStats.comp`는 `CompId | "OTHER"`뿐이라 화면은 "기타 대회"로만 쓸 수 있다. 이강인을 뺀 6명 모두 로그에 컵 경기가 1칸씩 있다. `data/players/korean.json`에 대회 원문 이름(또는 컵 id) 필드가 필요한지 M3-03 스키마 확인(사용자 확인 사항 — CLAUDE §8).
2. **주간 경계 시간대** — FR-90 "지난 월~일"의 기준(KST · UTC · 현지)이 없다. 김민재 10.25 16:30Z 프라이부르크전은 현지 · UTC로는 W43, KST로는 10.26 01:30이라 W44다. 브리핑은 '현지(UTC 하루)' 경기일을 쓴다(DESIGN §9.3 5줄 부제). M3-07에서 정한다 — 추천은 브리핑과 같은 UTC 기준.
3. **MVP 동점 규칙 없음** — FR-92 점수가 같을 때를 정하지 않았다. W44(진행 중)는 이재성 · 설영우 · 정우영 · 황희찬이 모두 1점(각 1경기 · 골 0)이다. 공동 MVP / 출전 시간 / MVP 없음 중 M3-07에서 정한다. 스키마 `mvp`는 slug 하나(nullable)라 공동 MVP는 스키마 변경이다.
4. **이적 1건 단위** — `transfers.json`은 선수 단위인데 김민재는 아스널 · 토트넘 · AC 밀란 이적설이 함께 있다(필드는 아스널 2장뿐). 행선지가 여러 곳일 때 카드 1장(최근 행선지)인지 행선지별 카드인지 M4-01에서 정한다. 타임라인에 단계 근거 카드(`history`, 2건)만 넣을지 같은 선수의 이적 분류 카드(7건, 단계 없음)도 보조로 넣을지도 같이 정한다.
5. **Tier 1이 나올 수 없다** — Tier 1 소스 2개(caughtoffside-romano · uefa-ucl-news)가 모두 비활성(약관)이라 지금 구성에서는 Tier 1 배지 · FR-103 "Tier 1이면 더 높게" 가중이 쓰이지 않는다. 디자인은 3단계를 다 두되, 필터의 "Tier 1" 선택지는 결과 0이 기본이다.
6. **스코어 방향이 섞인다** — 선수 로그는 소속팀 기준(for-against), 라운드 · 팀 일정은 홈-원정(DESIGN §3.5), 브리핑 문장은 주어 팀 먼저(D30). 한 화면(선수 상세)에 로그와 다음 경기가 함께 있어 표기 규칙(예: "승 3-1 · 원정")을 시안에서 정해야 한다.
7. **교체 출전 실례 없음** — 원장 16행에 `sub`가 0이다. '교체' 표현은 집계 전 fixtures(이강인 33분 등)로만 견본에 보인다.
8. **관련 뉴스 한쪽 쏠림** — `kr` 카드의 57%(71/125)가 이강인, 정우영 · 김지수는 0장이다. 선수 상세 뉴스 목록은 0장 빈 상태가 기본 상태의 하나다.
9. **컵 상대 팀 표기** — 마그데부르크 등 컵 상대 5팀이 `names.ko.json`에 없다 → 영문 원문 + `unknown-names.json` 적재 대상(`/add-name`).
