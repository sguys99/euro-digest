장점

  • "제 N호" 티켓 자체가 호 넘기기 장치가 된다 — 새 영역 없이 375·1280 모두 같은 자리, 첫 화면에 늘 보인다
  • 진짜 월 달력(요일 정렬·일요일 시작): 보는 호(반전)·최신 호(굵은 테두리 + "최신")·결호(점선 + 취소선 + "결호")·창간 전/발행 전(흐린 숫자)이 한 장에서 구분된다
  • 지면(5줄·피드)과 목차 열은 홈·/news/와 똑같다 — 아카이브 전용 레이아웃이 없다
  • 스텁 모티프(천공·노치·점선 칸)를 그대로 다시 쓴다. 새 모티프 0

단점

  • 티켓이 길어진다(실측): 375 +70px · 1024 이상 +76px → 375 첫 화면에 다 보이는 5줄이 4줄 → 3줄(1280은 4줄 유지)
  • 달력은 숨어 있어 한 번 눌러야 보인다(날짜 찾기가 주 용도인 사람에겐 한 단계 더)
  • 섬 JS가 필요하다(펼침·Esc·바깥 클릭·화살표 키·월 전환). 1024 이상은 팝오버라 위치·겹침(z 6) 처리
  • 홈 티켓에는 꼬리표가 없으면 티켓 모양이 페이지마다 달라진다 — /news/(최신 호)에도 달고, 홈에 달지는 따로 정해야 한다

구현 난이도

중 — Masthead에 꼬리표 칸(서버 컴포넌트: 앞뒤 호 계산은 빌드 때) + 달력 섬 1개(펼침 상태·포커스·Esc·바깥 클릭·화살표 키·월 전환). 월 격자는 서버에서 그려 두고 섬은 보이기·숨기기만 한다. 1024 이상 세로 천공의 아래 노치를 빼고 가로 천공과 T자로 만나게 하는 티켓 격자 변경.

번들·폰트 영향

폰트 변화 없음 — EuroDigest Sans 400·800 + Barlow Condensed 600·800(417.8KB, 2패밀리, concept-mix와 같은 파일). 새 색 0(모두 DESIGN 토큰). JS: 꼬리표는 0, 달력 섬 추정 gzip 1.5~2KB(시안의 바닐라 스크립트는 gzip 1.0KB · 아카이브·/news/ 페이지만, 초기 JS 141.6KB → 약 143.5KB / 예산 160KB). HTML(실측 gzip): 꼬리표 0.6KB + 한 달 격자 1.2KB = 약 +1.8KB(RSC 페이로드 중복 포함 약 +3KB). 지난 달 격자를 미리 그리면 달마다 늘어나니, 월 전환은 그 달 첫 호 링크로 두는 안을 제안.

접근성 메모

  • 꼬리표 = <nav aria-label="호 넘기기">, 이전/다음은 rel="prev"/"next" 링크 + 화면 밖 전체 날짜("10월 18일 일요일" — "10.18"을 소수로 읽지 않게)
  • 달력 버튼 aria-expanded·aria-controls, 열면 보는 호 칸으로 포커스, Esc·닫기 → 버튼으로 복귀. 비모달 펼침이라 포커스 가두기 없음
  • 격자 = <table> + caption + th abbr("일요일") + 발행된 날만 링크(aria-current="page"), 결호·창간 전·발행 전은 링크 아님 + 화면 밖 상태 글자. 화살표·Home/End 이동은 점진적 향상
  • 색 외 표식: 보는 호 = 반전 + aria-current, 최신 = 2px 테두리 + "최신" 글자, 결호 = 점선 + 취소선 + "결호" 글자, 비활성 월 버튼 = 점선
  • 티켓 안 포커스 링은 --ticket-fg(색 면 안 재정의). 꼬리표 아래 8px 여백으로 링이 지면(같은 크림색)으로 새지 않게 했다
