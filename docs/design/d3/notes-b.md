## 5. 구현 메모

- **글자형 아이콘은 path로 옮긴다**: “유”는 SVG `<text>`(EuroDigest Sans 800 — Pretendard 서브셋, OFL 1.1 · RFN ‘Pretendard’)다. 구현에서는 글리프 외곽선을 path로 뽑아 `temp-icons.ts` 좌표로 넣거나 SVG를 Playwright로 PNG로 굽는다. 글꼴로 만든 그림은 글꼴 재배포가 아니지만, RFN 글꼴의 수정판 이름 문제와 무관한지 착수 때 확인한다. 16px ICO는 시안 픽셀 격자.
- OG `.og--b`는 라이트 지면 토큰 값을 고정한다(`--paper` · `--ink` · `--ink-2` · `--brand-accent` · 라이트 대회 6색 · `--competition-foreground` = 지면색). `--og-*` 4개 제거, 새 토큰 0.
- 달력 기호(체크 · 엑스)는 SVG 경로, “!” · 대시는 Barlow 글자(서브셋 안). 칸 의미는 화면 밖 글자(`aria-label` — “10월 27일 (화) 제 16호 늦음 · 수집 완료 10:33”)가 맡는다(M1-34 달력과 같은 방식).
- 휴식기 달력은 `restPeriodOf` → `international-window` 판정(이미 있음) + `nationalWindows` 기간으로 그린다.

## 7. 자체 검토에서 고친 것

1. 달력 빗금 칸(A매치 기간) 숫자가 빗금(`::before`)에 덮여 지워짐 → 칸 안 글자에 `position: relative`.
2. 휴식기 ‘오늘’(11/12) 칸이 빗금 규칙에 덮여 반전이 안 되고 글자가 사라짐 → 반전 규칙을 빗금보다 뒤에.
3. 미래 날짜 숫자가 `--ink-disabled`(3.89 — 글자 미달) → `--ink-2` 400(6.46).
4. 30일 달력의 늦음 기호 · 시각을 레드로 칠했더니 11칸이 붉어 ‘레드는 괘선 한 줄’ 원칙이 깨짐 → 잉크(“!” 기호 · 시각 `--ink-2`)로. 레드는 실패 엑스 하나.
5. 크림 OG가 크림 지면 위 견본에서 경계가 없음 → 견본 보드에만 1px 점선 테두리(이미지에는 없음).
6. 비용 축 “100%”가 375에서 세로로 쪼개짐 → nowrap, 축을 막대 격자와 같은 열에 맞춤(50% 눈금 위치 일치).
7. 아이콘 ㅠ 다리가 레드 괘선에 닿음 → 글자 위로 14 · 괘선 아래로 4.
8. 범례의 ‘실패한 실행’ 항목이 375에서 낱말 단위로 세로 칸이 됨 → 두 항목으로 나누고 인라인 흐름으로.
9. “2027 년 6 월”처럼 숫자와 단위 사이가 벌어짐(flex gap) → 블록 흐름.
10. 하단 탭 sticky 캡처 문제 · 견본 날짜 정합 · 서브셋 밖 글자 제거(A와 같음).

## 8. 데이터 · 자리

- 데이터 출처 · 계산 함수 · 자리는 A와 같다(`notes-a.md` §8). 달력 칸의 시각은 그날 첫 발행 실행의 `finishedAt`(KST)이다.
- 30일 달력이 5주에 딱 맞는 것은 창 시작(10-04)이 일요일이기 때문이다. 다른 날에는 앞 칸이 빈다(M1-34 달력과 같음).
