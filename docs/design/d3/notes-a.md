## 5. 구현 메모 (M5-01 · M5-02)

- **글자형 아이콘은 path로 옮긴다**: 시안의 ED는 SVG `<text>`(웹폰트 Barlow Condensed 800)다. `temp-icons.ts`는 글꼴 없이 도형만 그리므로, 구현에서는 ED 글리프 외곽선을 한 번 path로 뽑아 좌표로 넣거나(Barlow OFL 1.1 — 글꼴로 만든 그림은 글꼴 재배포가 아니지만 착수 때 확인), SVG를 Playwright로 PNG로 굽는다. 둘 다 새 의존성 0(scope §6 #11). 16px ICO는 시안의 픽셀 격자(`P16`)를 그대로 쓴다.
- favicon.svg는 `<style>@media (prefers-color-scheme:dark)</style>`로 면 색만 바꾼다(시안 `.code` 견본). 파일 1개 + `<link rel="icon" type="image/svg+xml">` · `<link rel="icon" href="favicon.ico" sizes="32x32">`.
- OG는 `.og--a`가 라이트 티켓 토큰 값을 지역 변수로 고정한다(`--ticket` · `--ticket-fg` · `--ticket-fg-2` · `--paper` · 다크 대회 6색 · `--competition-foreground`). DESIGN §2.10의 `--og-*` 4개를 지우고 이 고정 방식으로 바꾼다(새 토큰 0).
- 시안 단독 렌더 `?solo=<id>&w=1200`이 M5-01 Playwright 스크린샷 방식의 견본이다(`screenshots/concept-a-og-*.png`).
- OG 고정 문구(“제 · 호” · 서명 · “시즌”)와 팀명은 `hasScoreLike` · 서브셋 커버리지 테스트 대상에 넣는다(“2026-27”은 기존 예외).

## 7. 자체 검토에서 고친 것

1. 링크 미리보기 카드 안 OG 글자가 쪼그라듦 — 미리보기 틀의 `p` 선택자가 OG 안 `p`까지 덮었다 → 자식 선택자(`.pv__x > p`)로.
2. `/offline/` 조형을 SVG(`preserveAspectRatio="none"`)로 그렸더니 폭에 따라 스텁 비율이 깨짐 → CSS 상자 두 개(실선 스텁 + 점선 본문)로.
3. 30일 띠 아래 날짜 눈금이 범례와 겹침 → 띠 아래 여백 34px.
