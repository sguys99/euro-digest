## 3. 휴식기 판정 규칙(1차 제안 그대로 — 확정)

1. **홈 오늘의 5줄에서만**(`variant="today"`). 날짜 아카이브 “이날의 5줄”은 S4 그대로(지난 호를 지금 설정으로 다시 쓰지 않는다).
2. 브리핑 mode `empty` + `emptyReason` `no-matches`(키 없는 옛 empty 포함). 결과 지연(`results-pending`)은 늘 오류 상자(D60).
3. 우선순위 **비시즌(`offSeasonFeature`) → A매치 휴식기(`restPeriodOf(발행일).reasons`에 `international-window`) → S4**.
4. 실을 경기 = `nationalWindowOn(발행일)` 기간의 `matchIds`(경기일 ±3일 · 이어지는 기간 합침 · `postponed` 제외), 킥오프 순.
5. 표기: 경기일 `MM.DD` N2 실선 + `(요일) HH:MM KST` + 상대 + 홈/원정 · 대회. `kickoffTbd`면 “시각 미정”. 킥오프가 지난 경기 = 날짜 `--ink-2` + “끝남”, 스코어 0.
6. 문구 = S4 문장 + 도장 “A매치 기간” + 기간. 원인 서술(“리그가 쉰다”) 없음. `national-team.json`이 없으면 S4.
7. “A매치 섹션으로 ↓”는 홈 A매치 섹션(M3-13 — 같은 판정으로 5줄 바로 아래)의 `id`로 가는 같은 쪽 앵커. 장소 · 소집 선수 · 결과는 그 섹션이 맡는다.
