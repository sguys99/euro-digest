장점

  • ‘Editorial, not portal’에 가장 충실하고 차분하다 — 아이콘 · OG · 빈 상태 · /status가 모두 지면의 조판이다
  • 크림 OG는 메신저의 흰 · 검 바탕 어디서나 ‘종이’로 읽히고, 대회 OG가 화면과 같은 라이트 대회 색을 쓴다
  • /status가 원장(리더 행) + 달력 표 + 소스 표라 3초 스캔과 스크린리더에 가장 강하다 — 30칸 모두 시각 숫자가 칸 안에 있다
  • 빈 상태가 기존 M1-34 달력 · D2 색인 컴포넌트를 재사용해 새 SVG가 거의 없다(가장 가벼움)

단점

  • 크림 아이콘은 흰 런처 바탕(경계 1.12)에 묻힌다 — 잉크 괘선 · 글자만 형태를 만든다
  • 한글 “유” 한 글자는 브랜드를 알아보는 근거가 약하다(“유” = 유튜브 · 유통 등으로도 읽힘)
  • 그림이라 할 요소가 적어 D3 기대(빈 상태 조형)와 거리가 있다 — 달력 · 색인은 조형보다 표에 가깝다
  • /status 달력 표는 375에서 칸이 49px로 좁아 시각(“20:28”)이 빽빽하다

구현 난이도

하~중 — 아이콘은 “유” 글리프 path 변환 1회 + 사각형 3개. OG 템플릿 1개 + 변형 3(대회 탭 · 팀 배지), 빈 상태는 M1-34 달력 · D2 색인 컴포넌트 재사용(CSS 위주), /status는 서버 컴포넌트 JS 0.
