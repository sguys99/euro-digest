## 5. 추천 — 혼합

**A 아이콘 · 파비콘 · OG 전부 + C 빈 상태(비시즌 · 휴식기 · 검색 0) + B `/offline/` 달력 + B `/status`(+ C 숫자판 3개를 머리로) + B 뒤표지 링크.**

- 아이콘과 OG는 서비스 밖에서 처음 보는 얼굴이다. A는 마스트헤드 티켓과 같은 그림이라 설치 · 공유 · 방문이 한 얼굴로 이어지고, D0에서 이미 고른 견본을 정리한 것이라 새로 정할 것과 규칙 변경이 0이다(C의 레드 넓은 면 규칙 변경을 피한다).
- 빈 상태는 이미 7곳에 퍼진 윤곽 숫자 언어를 키운 C가 가장 일관되고 가볍다. 단 오프라인만은 ‘무엇을 열 수 있는지’가 핵심이라 B의 두 주 달력이 낫다(M1-34 달력 재사용).
- `/status`는 독자가 ‘제때 나오나’를 확인하는 쪽이라 모든 값이 글자로 칸 안에 있는 B 원장 · 달력 · 표가 가장 정직하고 접근성이 좋다. C의 큰 숫자 3개를 머리에 두면 첫 화면 위계가 생긴다.

선택을 기다리는 중이다(구현하지 않음). 혼합 지시가 오면 `concept-mix.html`을 1회 만든다.
