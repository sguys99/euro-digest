## 5. 구현 메모

- **글자형 아이콘은 path로 옮긴다**: “5”(그리고 거터 변형의 1~4)는 SVG `<text>`(Barlow Condensed 800)다. 구현에서는 글리프 외곽선을 path로 뽑거나 SVG를 Playwright로 PNG로 굽는다(새 의존성 0). 16px ICO는 시안 픽셀 격자.
- OG 레드 면 `.og--cr`은 다크 티켓 토큰 값을, 크림 면 `.og--cp`는 라이트 지면 토큰 · 라이트 대회 값을 고정한다. `--og-*` 4개 제거, 새 토큰 0 — 단 레드 넓은 면 사용은 §1 규칙 변경.
- 팀 거대 약어 채움은 `kitTextColor`처럼 빌드 때 계산하는 규칙이다(`src/lib/kit-contrast.ts` 옆에 `kitLetterFill(상의, 하의, 면)` — 상의가 면과 3:1 이상이면 상의, 아니면 하의, 아니면 잉크). 데이터 · 스키마 변경 0.
- 점 그래프 좌표는 빌드 때 `runs.json` → %로 한 번 계산한다(선 · 면은 `preserveAspectRatio="none"` SVG + `vector-effect: non-scaling-stroke`, 점 · 글자는 HTML이라 늘어나지 않는다). 섬은 선택 날 상태만 갖는다. JS 없이도 숫자판 · 그래프 · 화면 밖 목록 · 기본 선택(오늘)이 보인다.

## 7. 자체 검토에서 고친 것

1. 점 그래프를 `preserveAspectRatio="none"` SVG 하나로 그렸더니 점이 납작한 타원 · 글자가 늘어남 → 선 · 면만 SVG, 점 · 축 글자는 % 좌표 HTML.
2. “공개 목표” 글자가 오른쪽 끝 점들과 겹침 → 창간 뒤 첫 칸 위로.
3. 제 100호의 “1” 꼭대기가 날짜 줄에 닿음 → 숫자 50 → 46cqw.
4. 흰 상의 팀(BMG · 토트넘)의 거대 약어가 흰 채움 + 잉크 테두리라 **윤곽 숫자처럼** 보임(윤곽 = 0 규칙과 충돌) → 채움 규칙(상의 → 하의 → 잉크) + 아래 띠에 2색.
5. 아이콘 5와 아래 괘선이 겹침 → 글자 위로 16, 괘선 아래로 8.
6. 375 날짜 버튼 폭 11px(44px 미달) → 1023 이하에서는 숨기고 ‹ › 44px 버튼으로.
7. 날짜 칸 hover를 `color-mix` 면으로 칠함(DESIGN 허용 목록 밖) → 아래 3px 잉크 2 밑줄.
8. scope의 ‘윤곽 호수’ → 실선(규칙 충돌 — §1).
9. 검색 0 유형 줄 “선수0”이 붙음 → 간격.
10. 하단 탭 sticky 캡처 · 견본 날짜 정합 · 서브셋 밖 글자(①②③ · │) 제거(A와 같음).
