### 1.3 axe `target-size`(WCAG 2.5.8)와 하단 탭

WCAG 2.2 태그를 켜자 375 대회(EPL · UCL) · 팀(바이에른) 페이지에서 `target-size` 위반이 하나씩 나왔다. 셋 다 **화면 아래 가장자리에서 sticky 하단 탭에 일부 걸친 링크**였다("partially obscured … 102.5×0.5px"). 같은 요소를 가운데로 옮기면 위반이 사라지고, 대신 그때 가장자리에 걸린 다른 행이 잡힌다 — 데이터와 스크롤 위치에 따라 바뀌는 판정이다. 하단 탭을 숨기면 모든 페이지 0이다.

그래서 `tests/e2e/support/a11y.ts` `axeWcag()`는 ① `target-size`를 뺀 WCAG 규칙 전체 → ② 하단 탭을 숨기고 `target-size`만, 두 번 돈다. 실제 누름 영역은 a11y.spec 44px 검사(요소마다 가운데로 옮겨 `elementFromPoint`로 확장 영역까지 잰다)가 더 엄격하게 본다. 'AI 작성' 라벨(46×20 상자)은 `::after`로 44px까지 넓혔는데 axe는 가상 요소를 보지 않는다 — 가운데로 옮기면 axe도 통과한다.

### 1.4 스크린리더 라벨 · 구조 점검에서 본 것

- `lang`: 루트 `ko`, 해외 원제목·출처명·러닝 헤드·리그 영문명은 `en`·`it`·`es`. `lang="ko"` 범위에 라틴 4낱말 이상 연속은 0(숨긴 검색 색인 기록 `[hidden]`은 보조기술이 읽지 않아 제외).
- 표: 순위표 · 시즌 기록 · 주간 리포트 · 소스 건강도 · 달력 모두 `caption`(또는 이름)과 `th scope`. 순위표는 팀 칸이 `th scope="row"`(행 머리글).
- 기호: ▲▼는 도형 + 화면 밖 "n계단 상승/하락", 폼 W/D/L은 칸 전체 `role="img"` "최근 리그 경기 5경기 (오래된 순): 패, 승, …", `/status` 띠 기호(● □ — ⊘ ◌ ✕)는 목록 항목 글자("정시 · 늦음 · 결호 · 실패 · 창간 전"), 선택 칩 ✓ · 외부 링크 ↗는 `aria-hidden` + 화면 밖 "(원문 …, 새 창)".
- 라이브 영역: 셸 공통 3개(발행 지연 `status` · 오프라인 띠 `status` · 토스트 `polite`) + 페이지 섬(뉴스 필터 결과 · 이적 결과 수 2벌 중 보이는 쪽 · 검색 요약 · `/status` 상태 줄 · 온보딩 진행). `assertive`·`alert`는 없다. 예외 하나: Next.js가 넣는 `next-route-announcer`(섀도 DOM `role="alert"` · `aria-live="assertive"`, 처음엔 비어 있음 — 클라이언트 이동 때 새 페이지 제목을 읽는다)는 프레임워크 기본 동작이라 둔다.
- 결과 가림 카드는 일부러 `aria-labelledby`를 걸지 않는다(가린 제목이 이름으로 새지 않게 — DESIGN §10).
