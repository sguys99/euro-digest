### 판정(`labels`)
- `must`: 같은 사건이라 반드시 한 클러스터여야 하는 쌍.
- `ok`: 서로 합쳐져도 되는 묶음 — 같은 경기의 기사·영상·감독 인터뷰처럼 같은 사건의 다른 갈래.
- `tolerated`: 다른 기사로 판정했지만 지금 하한에서 합쳐지는 쌍(알려진 오탐) — Rooney의 판정 의견과 Iraola 감독 반응(같은 퇴장 사건).
- 목록에 없는 쌍이 한 클러스터가 되면 오탐이다. 판정은 사람이 제목만 보고 했다(같은 인물의 다른 발언·후속 소식은 다른 사건).

### 원칙
잘못 합치기(다른 소식이 출처 스택 안으로 숨음)가 못 합치기(같은 소식 카드 2장)보다 나쁘다 — 하한은 `window`에서 오탐 0을
지키는 범위에서 재현율이 가장 높은 값으로 골랐다. 하한을 바꾸면 테스트가 오탐·재현 수 변화를 보여 준다.
