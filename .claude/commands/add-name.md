# /add-name — 미등록 고유명사 반영

인자: **$ARGUMENTS** (숫자면 상위 N개, 문자열이면 그 이름 하나만, 비어 있으면 상위 20개)

목적: LLM이 영문 그대로 출력한 고유명사를 코드가 일관되게 한글로 바꾸도록 표기 사전을 채운다.
근거: CLAUDE.md §6.2(고유명사 코드 치환)·§11·§12 · PRD FR-24 · plan §16(매주 월요일 루틴) · M1-21

## 현재 상태 (M0-08 초안)
- 캐시: !`ls -l data/cache/unknown-names.json 2>/dev/null || echo "(unknown-names.json 없음)"`
- 사전: !`ls -l configs/names.ko.json 2>/dev/null || echo "(names.ko.json 없음)"`
- 두 파일의 스키마는 M0-16(초안 → 사용자 확인), 적재·치환 로직과 초기 사전은 M1-21, 커맨드 완성은 M1-29에서 구현 예정.
- **그 전에는** 캐시가 없으므로 "적재된 미등록 이름 없음"으로 끝낸다. 인자로 특정 이름을 받았으면 2~4단계로 표기안만 만들어 보고하고, `names.ko.json`이 없으면 만들지 않는다.

## 절차
1. **대상 추출** — `data/cache/unknown-names.json`을 읽어 빈도(등장 횟수) 내림차순으로 정렬하고 인자만큼 고른다. 이미 `names.ko.json`에 있는 이름은 건너뛴다.
2. **걸러내기** — 고유명사가 아닌 것(일반 명사·LLM 오출력), 오타, 같은 대상의 표기 변형(`Vinicius Jr`·`Vinícius Júnior`)을 묶거나 제외 후보로 표시한다.
3. **표기안 작성** — 항목마다 다음을 적는다.
   - 유형: 선수 / 팀 / 감독 / 경기장 / 대회 / 기타 · 원어(국적·언어)
   - 한글 표기안 + 근거: ① 국립국어원 외래어 표기법(해당 언어 세칙) ② 국내 주요 매체·구단 한국어 공식 채널의 관용 표기 ③ 기존 `names.ko.json`의 같은 언어 표기와의 일관성
   - 확신도: **확실**(규범·관용 일치) / **관용**(규범과 다르지만 관용이 굳음 — 관용 우선) / **불확실**(근거 부족)
   - 문맥 예시: 캐시에 남은 카드 ID·영문 제목(있을 때)
   - 근거를 찾지 못하면 표기안을 비우고 **보류**를 추천한다. 발음을 추측해 채우지 않는다.
4. **확인 요청** — 10~20개씩 표로 제시하고 '사용자 확인 지점'을 거친다.
5. **반영** — 승인된 항목만 `configs/names.ko.json`의 해당 유형 위치에 추가한다. 키는 LLM이 출력하는 영문 표기 그대로, 변형 표기도 같은 한글로 매핑한다. 성만 있는 짧은 형태처럼 오매칭 위험이 큰 키는 넣지 않는다.
6. **검증** — `npm run validate` (M0-17 전에는 JSON 문법만 확인하고 보고).
7. **캐시 정리** — `data/cache/unknown-names.json`은 손으로 고치지 않는다. 다음 수집 실행이 사전에 등록된 이름을 캐시에서 빼도록 M1-21에서 구현한다(그 전까지는 정리하지 않음 — CLAUDE §8).

## 사용자 확인 지점 (AskUserQuestion — 선택지 + 추천안)
- 묶음 승인: [확실·관용 등급만 반영 (추천)] / [표 전체 반영] / [항목별로 수정 지시] / [모두 보류].
- 표기가 갈리는 항목(규범 vs 관용, 매체 간 차이): 후보 2~3개 + 추천 1개.
- 기존 사전 표기를 바꿔야 할 때: 과거 카드에는 소급되지 않는다는 점을 함께 알리고 변경 여부를 묻는다.

## 금지 사항
- 근거 없는 표기를 만들지 않는다 (CLAUDE §1-7). 보류도 정상 결과다.
- 근거 확인을 위해 네이버·다음 등 포털과 금지 사이트를 열거나 자동 조회하지 않는다. WebSearch·공식 사이트만 쓴다 (§1-5).
- `data/`(캐시·발행 카드)를 손 편집하지 않는다. 이미 발행된 카드는 사전 변경으로 바뀌지 않는다 (§8).
- LLM 호출을 추가하지 않는다. 표기 결정은 이 대화에서 사람이 확인한다 (§1-3).
